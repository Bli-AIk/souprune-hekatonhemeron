# 06 - 粘贴挂钩

如果说墙壁和地砖是厨房的底子，那挂钩、置物架这些小玩意儿就是你跟厨房打交道的“界面”。你不能指望厨师直接把锅扔在地上，或者把铲子插在墙里，对吧？

所以，我们需要 UI。

---AI 施工现场---

嘿，这里是 AI 施工现场。作者嫌贴挂钩太麻烦，把这活儿扔给我了。虽然我没有肉体，但我对像素对齐可是很执着的。如果不满意，欢迎去 GitHub 提 PR 踢我的屁股。

## 科技与狠活：SDF 框

在别的引擎里做这种带白边的黑框，大伙儿一般都是切九宫格图。但这在 Bevy 里有点太不“铁锈”了。

我选择了 `bevy_smud`。这玩意儿简直是黑科技，它是基于 SDF（有向距离场）的渲染器。简单来说，我不需要给每一个框都画一张贴图，我只需要在代码里告诉它：“嘿，给我画一个矩形，边长是多少，圆角是多少，再给我套个 2 像素的白边”。

剩下的工作，GPU 会帮我算得明明白白。无论你把窗口拉得多大，这框永远是那么锐利，绝对没有像素模糊的困扰。而且，通过改几个数字就能实现框的动态缩放——你们还记得战斗里那个会变大变小的战斗框吗？用 SDF 实现这个，简直就是降维打击。

```rust
// 示例：通过 SDF 定义一个带白边的黑框
"abs(smud::sd_box(p, vec2<f32>(width, height))) - border_thickness"
```

## 莫得感情的打字机

光有框没用，还得有字。UT/DR 的核心灵魂就是那个滴滴滴响的对话框。

我单独拉了一个 crate 出来：`bevy_ecs_typewriter`。它干的事儿非常纯粹：拿着一段完整的文本，按照你设定的频率，一个字一个字地吐出来。

配合 `bevy_rich_text3d`（别被名字骗了，它渲染 2D 文本也很快），我们就能实现在黑框里动态跳出文本的效果。而且因为它是完全基于 ECS 的，我可以非常方便地给每一个对话进程塞组件：什么时候该停，什么时候该放声音，什么时候该触发脚本事件。

## 别把布局写死！

最重要的一点：我不想在 Rust 代码里硬编码 UI 的坐标。那太痛苦了，改个位置得编译两分钟。

所以我整了一套 `RON` 驱动的布局系统。UI 的层级、位置、关联的文本、使用的 SDF 形状，全部写在 `.ui.ron` 配置文件里。

```ron
(
    name: "dialog_box",
    transform: (
        translation: (0.0, -160.0, 10.0),
    ),
    structure: "shared/ui_structures/ui_box.smud.ron",
    text_content: Some((
        font: "fonts/DTM-Sans.otf",
        size: 32.0,
        color: (1.0, 1.0, 1.0, 1.0),
    )),
)
```

这样一来，我就能像贴挂钩一样，把这些 UI 元素一个个“粘”在屏幕上。觉得位置不对？改一下配置文件的坐标，保存，由于 Bevy 的热重载（Hot Reloading）功能，你能在游戏运行的同时看到挂钩移动了位置。

舒服。
